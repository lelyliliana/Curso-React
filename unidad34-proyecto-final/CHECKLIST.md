# Lista de comprobación del proyecto

[Enunciado](PRACTICA.md) · [Plantilla](PLANTILLA_PROYECTO.md) · [Índice](../README.md)

- [ ] npm ci instala desde el lockfile con la versión Node indicada.
- [ ] check, tests y build terminan correctamente.
- [ ] Se identifica propietario de cada estado y de cada dato derivado.
- [ ] El reducer y actualizadores permanecen puros.
- [ ] Las tareas se validan y se modifican por id, incluso filtradas.
- [ ] Editar/cancelar no pierde la colección ni cambia otra tarea.
- [ ] Títulos duplicados conservan acciones independientes.
- [ ] Una carga corrupta no se sobrescribe durante montaje.
- [ ] El fallo de guardado conserva memoria e informa que no persistió.
- [ ] La API se valida y vacío no se presenta como error.
- [ ] Cancelación, timeout y respuesta obsoleta tienen casos reproducibles.
- [ ] Efectos retiran timers, listeners o peticiones que crean.
- [ ] StrictMode no se desactiva para ocultar errores.
- [ ] Las rutas se pueden abrir y recargar directamente.
- [ ] Labels, nombres, teclado, foco y anuncios se revisaron.
- [ ] No hay desbordamiento horizontal con ancho 320 px y texto duplicado.
- [ ] Datos con marcado se renderizan como texto.
- [ ] No se incluyen secretos en VITE_ ni en el repositorio.
- [ ] README diferencia servidor de laboratorio y publicación estática.
- [ ] Un fallo diagnosticado tiene evidencia y prueba de regresión pertinente.
- [ ] La entrega comunica límites de Storage, ids y coordinación entre pestañas.
